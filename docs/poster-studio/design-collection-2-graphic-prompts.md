# Poster Studio Design Collection 2 Prompt Files

Last updated: July 30, 2026

Design Collection 2 now has two separate prompt directions so the visual styles do not blend into each other during generation.

## Prompt Files

- [Heritage Khmer prompts](design-collection-2-heritage-khmer-prompts.md): use this for the older Khmer-inspired direction with kbach ornament, cultural decorative accents, laurel details, and Khmer landmark watermarks.
- [Modern White prompts](design-collection-2-modern-white-prompts.md): use this for the newer white-first international school direction with clean white backgrounds, architectural geometry, frosted-glass student cards, minimal accents, and no traditional Khmer photo-frame styling.

## Usage Rule

Choose only one direction for a generation batch. Do not mix heritage frame prompts with modern-white background prompts unless a hybrid design is intentionally requested.
